One image that sums up the world news of **Tuesday 17 November 2026**: markets tumbling (oil, gold and stocks down, Nasdaq in correction), Ukraine's 1,300-drone barrage on the Crimea Bridge, the tanker attacked in the Strait of Hormuz, five European nations planning a migrant return hub in Rwanda, the rocket failure that destroyed 40 Amazon satellites, and the cyberattack that rigged 178 major websites to steal card and crypto data.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` byte for byte into the output directory — the picture is the entry, drawn as six captioned panels under the day's date.
